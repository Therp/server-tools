To configure this module, you need to:

1.  Go `to Settings/Technical/FTP/Servers`
2.  Find your favourite protocol and configure connection settings
3.  In the form view of the record, edit file structure.
4.  If more folders are needed, just add data records with a proper
    xml_id
5.  If more servers are needed, just add data records with a proper
    xml_id
